Quickdot is a fork of Quik, which continues QKSMS. Quik and QKSMS are free software under the GNU General Public License v3.

## Features
- Scheduled Messages
- Message Backup
- Speech to Text and Text to Speech integrated within the app
- Message Blocking and Archiving
- Voice Messages
- Attachments of any type of file
- Message Sorting
- Delayed Sending
